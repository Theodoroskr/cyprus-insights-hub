# post-compliance-updates
- Managed schedule at 07, 08, 13, 14 UTC; posts only when the Cyprus-time hour is in `SLOT_HOURS` (10:00 and 16:00), one published ComplianceHub update per slot to every social account whose autopost setting is on (rules in `_shared/compliancePosts.ts`, publishing via `_shared/socialPublish.ts`). Why: two compliance posts a day, the same on every account, through summer and winter time.
- An update is posted once (unique posted row per item + platform in `social_compliance_posts`); only updates with an official date in the last `MAX_AGE_DAYS`; a slot that already ran is skipped; a slot with nothing new posts nothing. Admin "post now" uses its own `-manual` slot. Not counted against story or data-post limits. Why: no repeats, no stale backlog on social.
