# ingest-gemi
- GEMI Open Data has no statistics or date-filter endpoint, so counts come from `/companies`: active = `isActive=true` totalCount, stored for the current month with flag `p` (overwritten daily, final once the month ends); new registrations per completed month = difference of two "incorporated on/after day X" counts found by searching the `-incorporationDate` list (`countMonths` in `_shared/gemiRegister.ts`). Why: few calls instead of paging the whole register.
- Each run re-tests the key first, counts missing months since `GEMI_SINCE` plus the last 3 (late filings); a changed stored month goes to `stat_revisions`; unsorted answers or negative counts abort with stored figures kept; long first imports continue in a fresh call. No key = quiet skip. Why: no unverified or silently overwritten figures.
